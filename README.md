# 🔥 坦克大战 (Tank Battle)

一个使用 HTML5 Canvas 和原生 JavaScript 开发的经典坦克大战游戏。

## 🎮 在线游玩

直接在浏览器中打开 `index.html` 即可开始游戏！

[点击这里在线试玩](https://your-username.github.io/tank-battle/) (部署后替换链接)

## ✨ 游戏特性

- 🎯 **经典玩法** - 操控坦克消灭敌人，保护基地
- 🤖 **智能AI** - 敌人会自动追踪玩家并躲避障碍
- 💪 **升级系统** - 收集道具提升火力
- 🏆 **关卡系统** - 随着关卡提升，敌人会越来越强
- 💥 **爆炸特效** - 华丽的粒子效果
- 🎨 **精美画面** - 复古像素风格配合现代光影效果

## 🕹️ 操作说明

| 按键 | 功能 |
|------|------|
| `WASD` / `方向键` | 移动坦克 |
| `空格键` | 发射炮弹 |
| `P` | 暂停游戏 |

## 📦 游戏内容

### 敌人类型

| 类型 | 颜色 | 特点 |
|------|------|------|
| 普通坦克 | 红色 | 基础属性 |
| 快速坦克 | 橙色 | 移动速度快 |
| 重型坦克 | 深红色 | 血量高，需要多次攻击 |
| BOSS坦克 | 紫色 | 超高血量，大量积分 |

### 道具系统

- **P (Power)** - 提升火力等级，最高3级
- **♥ (Life)** - 增加一条生命

### 地图元素

- **砖墙** - 可被破坏，需要1次攻击
- **钢墙** - 较难破坏，需要3次攻击
- **基地** - 保护目标，被摧毁则游戏结束

## 🚀 本地运行

```bash
# 克隆仓库
git clone https://github.com/your-username/tank-battle.git

# 进入目录
cd tank-battle

# 在浏览器中打开
open index.html
```

或者使用本地服务器：

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve
```

然后在浏览器访问 `http://localhost:8000`

## 🛠️ 技术栈

- HTML5 Canvas - 游戏渲染
- 原生 JavaScript (ES6+) - 游戏逻辑
- CSS3 - 界面样式
